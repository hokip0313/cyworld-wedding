# 📷 사진 넣는 곳

- `profile.jpg` : 미니홈피 왼쪽 위 프로필 사진 (세로 3:4 권장). 없으면 도트 미니미 그림이 나와요.
- `og.jpg` : 카카오톡 링크 미리보기 사진 (가로 1200×630 권장)
- `gallery/` : 사진첩 사진. 올린 뒤 `config.js` 의 `gallery.photos` 에 파일 이름을 적어주세요.
- `bgm.mp3` : 배경음악 (선택). `config.js` 의 `music.src` 에 `'images/bgm.mp3'` 적기

⚠️ 공개 저장소에 올린 사진은 누구나 볼 수 있어요. 휴대폰 사진의 위치정보(GPS)가 남지 않도록
[사진 준비 도구](https://hyunim.github.io/wedding-invitation/prepare.html)로 정리한 사본을 올리세요.
